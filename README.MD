
## Технологии
* Python
* Django


## Как запустить

1. Склонируйте репозиторий
2. Активируйте виртаульное окружение
```commandline
venv\Scripts\activate.bat 

```  
3. Установите зависимости
```commandline
pip install -r requirements.txt
```

```
python manage.py runserver

```
